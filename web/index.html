Площадки: доступность форм

Каждая площадка проверяется сама: софт открывает страницу заказа и смотрит, на месте ли поле для ссылки, кнопка и не появилась ли капча. Если форма изменилась — площадка выключается из планов, чтобы заходы не улетали в пустоту.
A полный автопилот — форма простая, без капчи B автопилот с ожиданием — есть таймер/очередь C нужен браузер и человек на капче

Активные задачи таймеры считаются по серверному времени

Только подписчики сообществ ВК с числовой ссылкой. Используется публичный счётчик ВК; прочие метрики в этом режиме не запускаются. Автопилот должен быть включён. Капчи и ошибки сайта могут потребовать человека.
Подписчики в сообщество и в личную страницу — разные услуги. С включённой проверкой задача на неподходящий объект просто не создастся.

Сеть и проверка прироста

Используйте только конфигурации, которым доверяете и которые разрешено применять. Данные прокси и подписки хранятся в локальной базе без шифрования. Системный VPN/Amnezia работает как маршрут операционной системы.
Перед диагностикой сохраните изменения настроек. Проверка счётчика не отправляет заказ.

Капчи

Робот пробует чекбокс и локально распознаёт простые текстовые капчи. Успех не гарантирован: сложные задания и защита Cloudflare могут требовать ручного захода. После отказа при видимом окне задача ждёт ручного решения, иначе потребуется ручной заход. Платные сервисы не подключены.
Мин. интервал — пауза между любыми заходами, чтобы не долбить сайты и не ловить капчу. Рабочие часы — окно, в которое разрешены запуски.

Обслуживание

Каталог лежит в data/catalog.json — можно править руками и перезагружать без перезапуска. База: data/app.db, бэкапы раз в сутки в data/backups.

Как это работает

assisted (по умолчанию). Программа копирует вашу ссылку в буфер, открывает точную страницу с бесплатной кнопкой, держит таймер сайта и записывает результат. Финальный клик — ваш: на всех этих сайтах стоят собственные таймеры и проверки, обходить их бессмысленно.

auto (экспериментальный). Playwright-робот сам ищет поле, вставляет ссылку и жмёт кнопку. Нужно pip install playwright && playwright install chromium. Селекторы эвристические: после 3 неудач сайт отключается на 6 часов, чтобы не тратить время.
