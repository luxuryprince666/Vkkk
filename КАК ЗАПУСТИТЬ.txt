VK FREE FARM — как запустить
=================================

1. Нужен Python 3.9 или новее:  https://www.python.org/downloads/
   При установке на Windows обязательно поставьте галочку «Add Python to PATH».

2. Запуск:
   • Windows: двойной клик по run.bat
   • macOS / Linux: в терминале  ./run.sh
   • Или универсально:           python run.py

3. Откроется браузер с интерфейсом на http://localhost:8777
   Если не открылся — зайдите по этой ссылке вручную.

4. Что делать дальше (всё на первом экране «Накрутить»):
   • шаг 1 — выберите свою ссылку или нажмите «+ Добавить ссылку».
        Тип (сообщество / личная страница / запись) определится по адресу сам;
   • шаг 2 — выберите, что накрутить: «+10 подписчиков», «+25 лайков»… и нажмите «Накрутить»;
   • шаг 3 — программа откроет страницу сайта и положит вашу ссылку в буфер обмена.
        Вставьте её (Ctrl+V), нажмите кнопку на сайте, дождитесь и отметьте «Готово, накрутилось».
        Таймер покажет, когда сайт пустит снова;
   • кнопка «Поставить всё доступное в очередь» — программа сама растянет заходы по таймерам.

5. Если лень вести заходы вручную — вкладка «Цели»:
   • выберите ссылку и впишите, сколько нужно (например «лайки 100», «просмотры 200»);
   • задайте срок (2 дня, 12 часов…) и нажмите «Посчитать»;
   • программа ответит «выполнимо / впритык / невыполнимо» и покажет реальный максимум;
   • «Запустить цель» — заходы встанут в очередь и будут выполняться сами.
     В карточке цели видно прогресс, когда следующий заход, кнопки «Пауза», «+1 день», «Пересчитать».

6. Вкладка «Площадки» — честная картина по сайтам:
   • класс A — можно вести роботом сразу, B — есть таймер/очередь, C — нужен человек на капче;
   • кнопка «Проверить» открывает страницу заказа и смотрит, жива ли форма;
   • сломанные площадки выключаются из планов автоматически (после двух провалов подряд).

   Вторая строка меню («для профи») — сводка, каталог всех услуг, журнал и настройки.

7. Остановить программу: закройте окно консоли (или Ctrl+C в терминале).

Полезно знать:
   • Пароль от ВК нигде не нужен — только публичная ссылка.
   • Подписчики на сообщество и на личную страницу — РАЗНЫЕ услуги. Программа держит их
     порознь и просто не показывает услуги, которые к вашей ссылке не подходят.
   • Режимы «Все сайты / Без капчи / С капчей» — переключатель в шапке.
   • Кулдаун и объёмы любого сайта правятся вручную: кнопка с карандашом в «Все услуги».
   • Нужен интернет: программа открывает страницы сайтов и копирует ссылки в буфер.
   • Полностью автоматический режим (робот без участия человека) требует:
         pip install playwright
         python -m playwright install chromium

   • Для попыток распознать простые капчи с картинки дополнительно:
         python -m pip install ddddocr
     В Настройках должны быть включены «Решать капчи автоматически» и «OCR».
     Результат проверяет сайт; сложные капчи могут не пройти автоматически.
     При видимом окне нерешённую капчу можно решить вручную; в фоне окно не показывается.

Полная автоматизация для подписчиков сообществ ВК:
   В «Настройках» включите «Полная автоматизация» и «Автопилот», затем создайте цель.
   Нужна числовая ссылка сообщества; робот читает публичный счётчик ВК и запускает
   следующий сайт только после двух проверок прироста. При ошибке или неясном ответе
   очередь ждёт. Другие метрики в этом режиме не поддерживаются. Капчи могут потребовать
   человека. Не запускайте сторонние заказы параллельно.
