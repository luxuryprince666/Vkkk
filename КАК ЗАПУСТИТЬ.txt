VK FREE FARM — как запустить
=================================

1. Установите Python 3.9 или новее. На Windows отметьте «Add Python to PATH».

2. Запустите:
   • Windows: run.bat или python run.py
   • macOS / Linux: bash run.sh или python3 run.py
   • Откройте http://localhost:8777, если браузер не открылся автоматически.

3. На вкладке «Накрутить» вставьте в верхнее поле ссылку на сообщество ВК
   или публичный канал Telegram и нажмите «Накрутить». Программа сначала
   проверит реальный счётчик, затем будет пробовать подходящие площадки
   по одной. Для ВК проверяются API (если задан ключ), виджет, затем мобильная
   страница. Принимается точный счётчик с подтверждённым ID. Нужен доступ к
   счётчику и сайтам. Заказ и прирост не гарантируются.

4. Перед отправкой приложение заново измеряет исходное число подписчиков:
   пока открывалась форма или шёл таймер, оно могло измениться. Если этот замер
   недоступен, заказ не отправляется. После действий драйвера счётчик наблюдается
   минимум пять минут; рост подтверждается несколькими замерами, затем —
   стабилизацией. В отчёте исходное и последнее значения, изменение, время
   первого обнаружения роста и причина, если проверка не состоялась. Можно
   скачать подробный JSON.

5. «Не проверено» — это не ноль и не доказательство неисправности площадки.
   Органические подписки, отписки и предыдущие заказы могут повлиять на счётчик.
   Не отправляйте другие заявки параллельно. Уже отправленную заявку кнопка
   «Остановить» не отменяет. После неясной отправки повтор требует вашего
   отдельного подтверждения риска.

6. Для браузерного робота нужны дополнительные компоненты:
       python -m pip install playwright
       python -m playwright install chromium
   Некоторые капчи нужно решать в видимом окне, на сервере без экрана это может
   быть невозможно. Сетевые настройки позволяют использовать только ваши или
   разрешённые прокси, VLESS и системный VPN/Amnezia. Сначала сохраните настройки.

Ручные заходы и расчёты ниже на экране не подтверждают фактический прирост.
Сервер по умолчанию доступен только на этом компьютере и не имеет авторизации.
Не открывайте его в недоверенную сеть. Подробнее: README.md.
